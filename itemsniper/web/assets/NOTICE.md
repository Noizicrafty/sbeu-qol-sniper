# Sources for the hideout interface

Reference: https://tarkov-market.ru/progression/hideout
Captured: 2026-11-11.

`hideout-reference.json` contains the publicly displayed hideout SVG outline,
26 module SVG icons, their displayed names and their 800 × 700 map coordinates.
`hideout-details.json` contains the displayed build times, bonuses, module
prerequisites and reference construction costs of 68 levels.

The reference interface is designed and maintained by ggDiam / Tarkov Market.
Game content belongs to Battlestate Games and its licensors. Original attribution:
https://tarkov-market.ru/about

Font files are the Bender fonts served by the reference page:
https://cdn.tarkov-market.ru/fonts/Bender.woff2
https://cdn.tarkov-market.ru/fonts/Bender-Bold.woff2

These files are local snapshots, not a live copy of the site's service. Material
quantities and FIR rules still come from the separate wiki catalog; player levels
and inventory come from the user's locally confirmed screen captures.
Construction costs are reference snapshots, not current market quotes.

The Falling Skies banner uses the game screenshot supplied by the user as a local
UI reference. Game artwork belongs to Battlestate Games.
Quest definitions: Tarkov.dev and szepiz/tarkov-quest-data. Story chapter entries
are attributed to their upstream tracker overlay in the latter source metadata.
