# Публичные справочники

`catalog.json` содержит предметы RU/EN и требования убежища, `progression.json` — квесты, пункты и зависимости. Снимок данных подготовлен 12 ноября 2026 года из публичных источников, перечисленных в исходных полях `source` и в [атрибуции](../itemsniper/web/assets/NOTICE.md).

Здесь нет уровней игрока, прогресса заданий, снимков инвентаря, игровых кадров или абсолютных путей к файлам. Изображения всех предметов и модели OCR в Git не включены: подготовка окружения загружает их отдельно. Справочник может содержать архивные записи и устаревать между обновлениями игры.
